# Nemos Backpacks

NeoForge 1.21.1 port of Nemos Backpacks, a vanilla-style backpack mod for Minecraft.

## Features

- 17 color variants — all 16 dye colors plus a neutral default
- 6 size tiers tied to material:
  - Default — 9 slots
  - Copper — 18 slots
  - Iron — 27 slots
  - Gold — 36 slots
  - Diamond — 45 slots
  - Netherite — 54 slots
- Equip system places a worn backpack in a dedicated slot so it stays accessible without occupying main-hand, off-hand, or armor slots
- Upgrade Smithing Templates found in world structures expand a backpack one tier at a time

## Version

This branch targets Minecraft 1.21.1 on NeoForge.
